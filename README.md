## Descripción del Proyecto
Este repositorio contiene el desarrollo y resolución del Trabajo Individual sobre **Métodos de Incertidumbre**. El proyecto evalúa dos problemas mediante el entorno de programación R y RMarkdown:

1. **Problema 1:** Análisis de una matriz abstracta de decisión bajo situación favorable y desfavorable mediante cada función/método individual de Incertidumbre por separado (Wald, Optimista, Minimax, Hurwicz y Laplace).
2. **Problema 2:** Caso real aplicado a la reestructuración de liquidez bancaria en el marco de Basilea III/IV ante escenarios de tipos de interés, resuelto con la función R que devuelve la resolución de todos los métodos en una sola tabla.

## Estructura del Repositorio
* `Trabajo Indivual TD Enunciados.Rmd` / `.pdf`: Exposición formal de los problemas y plantilla de respuestas V/F.
* `Trabajo Indivual TD Soluciones.Rmd` / `.pdf`: Código R completo, ejecución de funciones y justificación detallada de cada cuestión.
* `teoriadecision_funciones_incertidumbre.R`: Script con las funciones locales cargadas en el proyecto.
